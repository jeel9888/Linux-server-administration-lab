# Linux Server Administration & Security Lab

## Project Overview

This project documents the deployment and administration of a virtualized Ubuntu Server environment using Oracle VirtualBox.

The purpose of this lab is to develop practical skills in Linux system administration, networking, remote server administration, and basic security hardening.

## Lab Environment

| Component | Configuration |
|---|---|
| Host OS | Windows |
| Virtualization | Oracle VirtualBox |
| Server OS | Ubuntu Server LTS |
| CPU | 2 cores |
| RAM | 4 GB |
| Storage | 25 GB |
| Network | Bridged Adapter |

## Technologies & Tools

- Ubuntu Server
- Linux
- Oracle VirtualBox
- OpenSSH
- UFW Firewall
- TCP/IP
- GitHub

## Objectives

- Deploy an Ubuntu Server in a virtualized environment
- Configure basic network connectivity
- Update and maintain the Linux server
- Configure and manage SSH
- Configure a host-based firewall
- Practice remote server administration
- Manage Linux users and permissions
- Apply basic security hardening
- Document troubleshooting and configuration steps
